# DevaRO Calc

A modern, Pre-Renewal Ragnarok Online calculator built with React, TypeScript, and HeroUI.
Based on the logic and data from [rocalc.com](https://rocalc.com).

## Project Structure

- `src/data/`: Contains the migrated data files (items, monsters, skills, etc.) from the original calculator.
- `src/components/`: React components.
- `src/types/`: TypeScript interfaces.

## Development

1. `npm install`
2. `npm run dev`
